Patas de Esperança - Experiência Prática II

Projeto front-end em HTML5 e CSS3 para uma ONG de proteção animal.

Arquivos:
- index.html: página inicial
- projetos.html: projetos e componentes de feedback
- cadastro.html: formulário de voluntariado
- style.css: Design System, Grid, Flexbox, responsividade e estados interativos
- imagens/: logo em PNG, WebP e SVG

Recursos demonstrados:
- Variáveis CSS e Design System
- CSS Grid de 12 colunas
- Flexbox
- 5 breakpoints: 480px, 768px, 1024px, 1280px e 1440px
- Navegação responsiva com menu móvel e submenu
- Estados hover, focus, active, disabled, valid e invalid
- Badges, alertas, toast e modal com <dialog>
- Formulário HTML5 com validação nativa
